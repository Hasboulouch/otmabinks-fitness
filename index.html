Comment ça marche ? +

Une séance validée prolonge ta série. Un jour d’entraînement manqué utilise automatiquement un gel, dès le lendemain. Le gel protège ta série sans ajouter de jour. Après trois gels dans le même mois, le prochain jour manqué casse la série. Trois nouveaux gels arrivent le 1er de chaque mois, sans cumul. Le dimanche compte comme repos dans une série active, sans gel. Le suivi démarre à ta première séance validée.
